# Palette and shoulder checkpoint — October 16, 2026

## Changes
- Desktop tools form a compact left palette. Move it by the dedicated Tools handle (or arrow keys when focused); Reset position restores its default. Resize also restores the default. Minimize keeps the tool icons available.
- Phones start with a compact horizontal tool row and a visible instruction. Expand (+) reveals settings. Essential actions remain in a separate stationary footer, with a substantially wider speed track and safe-area allowance.
- Desktop framing moves down slightly to leave more room above taller forms.
- Hands inward shoulder pressure uses a narrower area of influence. The cavity follows local outer-radius changes before existing wall and floor safeguards run. Low contact reaches the foot. Rib and Sponge algorithms are unchanged.

## Evidence and limits
Screenshots are real browser UI captures, not injected profiles. Phone widths 320, 390 and 430 were inspected, along with a 1024×650 desktop. Palette drag, reset and minimize were exercised. Mobile expanded Rib instructions and settings fit at 320×568. Expanded panels deliberately occupy more space; minimizing restores working room.

The fresh 10 lb porcelain trial used only real pointer gestures: open, deepen, widen, pull the belly outward and close the shoulder inward. The resulting shoulder narrows while a fuller belly remains below. Undo was exercised and its resulting state captured. This is a shaping smoke test, not proof of a finished moon jar or physically even wall thickness. The model still protects radial thickness rather than true thickness normal to the curved surface.

The in-app browser became unavailable during the remaining checks. Redo, final firing and live-site visual verification were not completed in this browser session; do not describe them as passed. No real iPhone/iPad performance test was available. Geometry and material suites provide separate programmatic coverage.
