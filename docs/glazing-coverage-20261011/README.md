# Glaze coverage and shelf checkpoint — October 11, 2026

Local review only. Do not deploy without Salene's review.

Implemented:
- Stronger glaze dabs, connected strokes across the wrap seam, breaks on missed contact/surface transitions.
- Fine brush down to 0.1×; 512px paint texture on phone and desktop.
- Undoable Coat whole piece with selected color; glaze shader excludes the underside by local height. Matte before firing, glossy after.
- Phone coat/brush row and recovery/color row; tablet palette wraps into two rows.
- Hands can squeeze an existing opening inward while preserving wall thickness. Original stable ring targeting is retained after an experimental moving target made shaping less predictable.
- IndexedDB shelf with original localStorage backup/migration and fallback. Serialized transactions merge concurrent writes. Updated timestamps prefer newer fallback copies. Delayed save completion cannot overwrite a new clay's status.
- Native web bundle includes shelf-store.js. Native app execution remains untested.
